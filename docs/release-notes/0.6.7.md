# 0.6.7 stable release

Promoted on October 20, 2026 after user acceptance. The Windows x64 installer and portable archive are unchanged from the accepted candidate; nothing was rebuilt or re-uploaded. The 0.6.6 stable downloads remain available for rollback.

- Window layouts record snapped windows at the size Windows actually shows, and restoring them no longer jumps back to the pre-snap size. Restored windows leave the Snap group once they are placed.
- Layout previews draw only the windows currently visible on the desktop, stacked by their real z-order, so windows in front cover the ones behind them.
- Each layout can record its own global shortcut; pressing it restores that layout from any application. Combinations already owned by another program are reported as failed instead of being silently ignored.
- A per-layout exclusion list skips chosen applications in recording, restoring and previews.
- Layout names save when the field loses focus, and the one-click restore button is smaller and centered.
- Dragging a window above the top edge past the move-out ratio now shows the full-width blue line and tucks it into the top edge, matching the left, right and bottom edges.
- Layouts remember windows that were tucked away at an edge and restore the same collapsed state instead of leaving them half off-screen.
- The topmost pin adopts windows that are already topmost when the helper restarts, so the pin is visible again and clicking it cancels that state.
- Closing a screenshot or pin overlay no longer expands edge-hidden windows underneath it.
- Interface polish: a seven-step type scale, consistent corner radius, motion and elevation tokens, brighter dark surfaces, pressed-state feedback and focus rings, without changing the layout skeleton.

Run one host at a time. Keep the desktop interface at ordinary permissions and elevate only its helper when needed. The helper remains a separate component that must be installed explicitly; the desktop installer and portable archive bundle the matching helper payload. Taskbar appearance remains an off-by-default experimental feature.
