- **The paused-app list for drag and resize now actually applies to maximized windows.** The list
  used to be evaluated *after* a maximized window had already been restored into a floating one, so
  a listed app was still pulled out of fullscreen and moved. The check now runs first: when the list
  matches, the helper does not touch the window at all and `Alt + mouse` is left entirely to the
  target program.
- **The "More" navigation icon is drawn with CSS** instead of the `•••` character, so its three
  dots no longer drift in size, spacing or baseline under fonts such as Segoe UI Variable and
  Microsoft YaHei. Contributed by @Victor-Quqi (PR #3).
