- **The paused-app list for drag and resize now actually applies to maximized windows.** The list
  used to be evaluated *after* a maximized window had already been restored into a floating one, so
  a listed app was still pulled out of fullscreen and moved. The check now runs first: when the list
  matches, the helper does not touch the window at all and `Alt + mouse` is left entirely to the
  target program.
- **Brightness control.** Hot zones and mouse gestures can now raise or lower the brightness of the
  display you trigger on, with continuous adjustment through the wheel and the slide gestures. On
  Windows an internal panel goes through the system interface and DDC/CI-capable external displays
  are supported as well; Linux X11 and macOS backends are present but have not been verified on real
  hardware yet.
- **Volume adjustments now follow how far you scroll.** Previously any trigger moved exactly one
  step no matter how fast the wheel turned. The change is now proportional to the requested motion,
  up to six steps at once; one wheel notch is still one step, sub-step motion carries over to the
  next adjustment, and it is dropped when you reverse direction.
- **Fixed a volume key that could be left logically pressed.** When injection was only partly
  accepted, the helper reported the failure without releasing the key. It now sends the missing
  release and includes the actually delivered event count in the error.
- **Fixed an unreadable failure when an internal panel rejects brightness changes.** A failed COM
  initialisation used to be treated as "this display has no internal brightness channel" and
  silently fell back to DDC/CI; the real cause is now reported.
