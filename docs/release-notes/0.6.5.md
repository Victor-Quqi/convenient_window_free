# 0.6.5 pre-release candidate

Windows x64 online-acceptance candidate. Stable 0.6.4 downloads remain available.

- Customize hide/restore animation duration while keeping the 160 ms default. Fix windows failing to tuck away after duration changes or desktop clicks.
- Keep qualified side-edge blue lines visible during paused drags. A growing top-edge line now requires a completed hold before release; early release preserves native Snap.
- Reduce redundant anywhere-move/resize updates and add 60/120/240 Hz presets with a custom update-rate limit.
- Isolate ordinary shortcuts during native capture, preserve displayed bindings across region changes, and fix corner-click maximize/minimize targets.
- Refresh settings surfaces and spacing, place common choices before numeric tuning, and fix clipped settings after disabling animation or focusing switches.

Run one host at a time. Keep the desktop interface at ordinary permissions and elevate only its helper when needed. Taskbar appearance remains an off-by-default experimental feature. Real UAC, multi-monitor/DPI, installation/upgrade and host shortcut acceptance are still required.
