# 0.6.6 pre-release

This is a pre-release test candidate for Windows 11 x64. Download the installer or the portable archive, run the checks you care about, and report back; the 0.6.5 stable downloads remain unchanged and can be reinstalled at any time.

- Save the current desktop as a window layout: ordinary windows keep their position, size, maximized and topmost state, and can be restored in one click. Minimized windows are restored as well; closed, inaccessible or identity-mismatched windows are skipped individually instead of failing the batch.
- Compose the bottom tabs from Settings → Feature entries: drag bubbles between the highlighted row and the spare row, and click a bubble to open that feature. The highlighted row keeps up to four features, the Center is always present, and dropping a fifth entry on a full row shows a red "full" state instead of adding it.
- Bottom tabs and the settings bubbles now share one icon set, so the same feature always uses the same glyph in both places.
- In a narrow layout the bottom tabs keep icons only instead of squeezing the labels; names remain available through hover titles, focus and screen readers.
- Restore re-checks each window's process name, class and title before applying changes, so duplicate browser or editor windows are not redirected to the wrong target.

Run one host at a time. Keep the desktop interface at ordinary permissions and elevate only its helper when needed. The helper remains a separate component that must be installed explicitly; the desktop installer and portable archive bundle the matching helper payload. Taskbar appearance remains an off-by-default experimental feature.
