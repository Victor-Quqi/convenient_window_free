# 0.6.4 development candidate

Local development candidate only; not published. Existing 0.6.3 stable assets remain unchanged. Interactive UAC, multi-monitor/DPI, taskbar recovery and host-adapter acceptance remain required.

- Fix topmost pins disappearing behind their stationary owner when stacking order changes, without placing them above every other topmost window.
- Keep pinned screenshots at their original pixel dimensions. The default-on offset moves them 16 px down/right; turning it off covers the captured area. Large or edge-adjacent images may extend off-screen instead of being automatically resized.
- Preserve unfinished numeric input until blur/Enter, keep drafts isolated between monitor/zone/trigger contexts, and wait for real display identities before saving monitor profiles.
- Preserve early helper shutdown notifications so starting and immediately stopping does not wait for a second exit request.
- Refresh the serializer dependency to the patched locked version without forcing a major test-tool migration.
- Add current-session Windows administrator-helper mode while keeping the host and configured commands at ordinary permissions. Re-query failed switches; show unknown if actual permission state cannot be confirmed.

Administrator mode does not support protected processes or scheduled elevated login/startup (issue #20 phase two). Each host adapter requires its own runtime acceptance. Hosts share the single-instance boundary and fixed port 56873. See [candidate tests](../testing.md#064-local-candidate-acceptance).
