# Convenient Window 0.6.3

## Second-transfer focus

- Added a minimal taskbar appearance prototype with transparent, acrylic, and solid materials plus selectable taskbar layouts.
- Added an edge-hide animation switch. When disabled, edge hide and restore complete immediately to reduce animation work.
- Synchronized settings, protocol handling, and Chinese/English copy between the uTools and standalone desktop hosts.
- Taskbar appearance remains opt-in and Explorer restart/recovery guidance remains available.

## Known scope

- Taskbar appearance depends on Windows 11 Explorer and may need to be reapplied after Explorer or system updates.
- This candidate targets Windows 11 x64; taskbar materials are still a prototype and require real desktop acceptance.
- The application and installer are unsigned, so Windows may show an unknown-publisher or SmartScreen warning.
