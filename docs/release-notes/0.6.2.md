- **修复提示条显示。** The uTools adjustment indicator is now built as a self-contained page, with reliable data delivery and explicit native window appearance settings; volume and brightness feedback no longer appears as an empty pale outline.
- **修复外接屏亮度回退。** When Windows WMI and DDC/CI are both unavailable, the helper uses a per-display GDI gamma software fallback from 70% to 100% and restores the captured gamma ramp on normal shutdown.
- **修复屏蔽应用中的拖动快捷键失效。** The low-level mouse hook checks `windowDrag.pausedApps` before consuming the configured modifier+mouse press. Blocked apps receive the original press, motion, and release unchanged, so Blender-style Alt/Ctrl/Shift mouse combinations remain usable.
- **桌面版与 uTools 使用同一份 helper 修复。** Both hosts are built against the shared helper fix; the public helper source is kept in the same repository and release workflow.
